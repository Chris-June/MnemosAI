# Meeting Maestro

## Overview
Meeting Maestro is an intelligent meeting summarization tool that leverages AI to generate concise, actionable summaries.

## Setup
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file with your OpenAI API key
4. Run `npm run dev`

## Technologies
- React
- TypeScript
- Express
- OpenAI API
- Vite
